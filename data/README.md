# Data

This folder contains the datasets used in the Retail Sales Analysis project.

* `Sample_Data.csv` — Original dataset containing 240 sales records.
* `Regional_Revenue_Analysis.csv` — Summary of sales records, total revenue, and revenue percentage by region.

## Dataset Information

The original dataset is used for analysis with SQL, Excel, Python, and Power BI.

The regional revenue summary provides insights into the revenue contribution of each region.
