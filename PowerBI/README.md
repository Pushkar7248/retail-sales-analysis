# Power BI Dashboard

This folder contains the Power BI dashboard developed for the Retail Sales Analysis project.

## Dashboard Features

* Total Revenue KPI
* Total Sales Records KPI
* Average Sales Value KPI
* Sales by Region
* Revenue by Product
* Monthly Revenue Trend
* Region and Product slicers

## File Contents

* Power BI dashboard file (.pbix)
* Dashboard screenshots
* Business insights report

## Purpose

The dashboard provides an interactive view of retail sales performance and helps identify regional performance, top-performing products, and monthly revenue trends.
